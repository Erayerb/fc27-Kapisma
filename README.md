# FC27 Kapışma

Statik, PeerJS tabanlı çok oyunculu oyun. Özel backend veya veritabanı gerekmez.

## GitHub Pages

Depo ayarlarında **Settings → Pages → Deploy from a branch** seçin; yayın kaynağını `main` ve `/(root)` olarak ayarlayın. Kök dizindeki `index.html` oyunu başlatır.

PeerJS'in CDN ve sinyalleşme hizmeti için oyuncuların internet erişimi gerekir. Oda sahibi oyunun durumu için yetkilidir ve oyun boyunca sayfayı açık tutmalıdır; oda verileri sunucuda saklanmaz.
